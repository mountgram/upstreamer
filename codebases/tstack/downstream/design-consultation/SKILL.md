# Design Consultation

Use this skill when the user wants design direction rather than immediate implementation.

## Inputs

- Product goal and target audience.
- Existing screenshots, flows, or code if available.
- Constraints such as brand, platform, accessibility, deadline, and technical surface.

## Workflow

1. Restate the user goal in product terms.
2. Identify the primary user job and the emotional tone the design should create.
3. Name the biggest design risks: hierarchy, clarity, trust, density, accessibility, or motion.
4. Propose two or three distinct directions with tradeoffs.
5. Recommend one direction and list the first concrete changes.

## Output

- Design diagnosis.
- Recommended direction.
- Prioritized changes.
- Open questions only if they block the next step.
