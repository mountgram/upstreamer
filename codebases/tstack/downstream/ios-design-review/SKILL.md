# iOS Design Review

Use this skill to review an iOS UI against product goals and platform expectations.

## Review Areas

- Navigation structure and back behavior.
- Touch targets, spacing, typography, and visual hierarchy.
- Dark mode, Dynamic Type, VoiceOver labels, and contrast.
- Loading, empty, error, and permission states.
- Platform conventions for sheets, tabs, toolbars, lists, and gestures.

## Workflow

1. Understand the target user flow and success criteria.
2. Inspect screenshots, simulator output, or code depending on what is available.
3. Compare the current UI to iOS conventions without flattening the brand voice.
4. Report issues by severity and include concrete fixes.

## Output

Findings first, then a short polish plan.
