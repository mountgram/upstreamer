# Design Shotgun

Use this skill when the first idea is too narrow or the user wants creative range.

## Directions

Create three to five options that differ meaningfully in structure, tone, density, or interaction model. Do not create superficial color swaps.

For each direction, capture:

- Name and one-sentence concept.
- Target user feeling.
- Layout and information hierarchy.
- Strengths, weaknesses, and implementation risk.

## Selection

Score each option against the product goal, clarity, accessibility, feasibility, and memorability. Recommend one option or a hybrid, then list the first implementation steps.
