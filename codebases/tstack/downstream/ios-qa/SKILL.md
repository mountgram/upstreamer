# iOS QA

Use this skill to validate an iOS change on simulator or device with practical coverage.

## Plan

- Identify changed screens, user flows, and platform integrations.
- Include happy path, interruption, offline, permission, rotation, and accessibility checks when relevant.
- Prefer real device coverage for camera, push, Bluetooth, location, and performance-sensitive features.

## Execute

1. Build and launch the app using the project's normal tooling.
2. Run available unit, UI, or snapshot tests.
3. Manually exercise the risk-focused scenarios.
4. Capture reproduction steps for every issue.
5. Distinguish product bugs from test environment limitations.

## Report

List tested device or simulator, OS version, build identifier, checks run, defects found, and remaining risk.
