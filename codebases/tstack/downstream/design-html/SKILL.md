# Design HTML

Use this skill to make a quick static design artifact that communicates layout, tone, hierarchy, and responsive behavior.

## Principles

- Prefer one self-contained HTML file when possible.
- Use semantic markup and accessible labels.
- Include realistic content, not placeholder filler.
- Show mobile and desktop behavior through responsive CSS.
- Avoid dependencies unless the user explicitly asks for them.

## Workflow

1. Clarify the screen, state, and audience.
2. Choose a visual direction before writing markup.
3. Build the smallest static artifact that demonstrates the design.
4. Check contrast, spacing, focus states, and small-screen layout.
5. Explain what is represented and what remains unresolved.
